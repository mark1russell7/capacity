capacity

The cost of a request in CPU, memory, garbage collection, event-loop lag, network bytes and latency, as laws over each load variable. Each law comes from timed runs in CI, with its interval.

How much of the goal is done

The goal is a law for each load variable, each measure and each subject, on each CPU model. Each cell below is one of these laws. The page counts the cells from the law files of the repository.

    The cost of the service runner

    Each chart puts the cost that the service runner adds on top of the cost of a bare Node server, over the request rate. The charts come from the compositions of the repository. Move the pointer on a chart, or use the arrow keys, to read the values at each rate.
